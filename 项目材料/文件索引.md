## 原生天气文件族

- `data_raw/weather/gfs/points/*.json`：1,461 个下载的原生 GFS 格点片段，保留原变量单位；批次关系见 run_manifest.csv。
- `data_raw/weather/era5/points/*.npz`：4 组原生 ERA5 点序列和元数据，温度、风、气压降水、辐射；不是模型生成值。

## 模型代码

- `model/__init__.py`：本地 Python 包标记，支持模块运行、导入和分组测试发现。
- `model/configuration.py`：读取光伏配置及生成参数指纹的公共工具。
- `model/generate_load/__init__.py`：本地 Python 包标记，支持模块运行、导入和分组测试发现。
- `model/generate_load/config.json`：负荷种子、片段候选、形状替换、缩放、ERA5 门槛和测试集合配置。
- `model/generate_load/fragment_load.py`：ERA5 条件下的配对多日片段、少量单日替换、边界评分及独立测试。
- `model/generate_load/sample_load.py`：负荷生成的命令入口。
- `model/preprocess/__init__.py`：本地 Python 包标记，支持模块运行、导入和分组测试发现。
- `model/preprocess/download_gfs.py`：组织上海 GFS 按年下载，完整总表存在时直接复用并刷新对齐。
- `model/preprocess/fetch_era5_land.py`：通过已有 CDS 授权下载该城市 ERA5 点序列，处理小时区间和单位。
- `model/preprocess/fetch_gfs.py`：该城市 GFS 批次选择、决策前发布时间检查和变量标准化。
- `model/preprocess/fetch_gfs_api.py`：点查询接口补齐该城市 GFS 缓存，包含低并发和重试。
- `model/preprocess/fetch_gfs_mirror.py`：从分块镜像提取该城市 GFS 格点，支持断点缓存。
- `model/preprocess/process.py`：从原生格点离线重建并互补天气；从工作簿重构、补全和标准化负荷。
- `model/pv/README.md`：光伏运行方式、字段和物理计算方法说明。
- `model/pv/__init__.py`：本地 Python 包标记，支持模块运行、导入和分组测试发现。
- `model/pv/config.json`：上海参考坐标及示例光伏阵列参数；不是实测站点设备。
- `model/pv/run.py`：批量生成两套四年光伏，并记录输入、代码及输出哈希。
- `model/pv/simulate.py`：太阳位置、辐照分解、组件温度、直交流转换和损耗物理模型。
- `model/pv/光伏发电功率仿真流程图.png`：恢复的光伏计算流程示意图，当前参数以配置为准。
- `model/run.py`：统一运行负荷、光伏和检查；支持仅检查、仅负荷、仅光伏及重建原始输入。

## 隐藏运行环境

- `.runtime/requirements.txt`：运行依赖要求；`.runtime/requirements-lock.txt` 为已安装版本记录。
- `.runtime/python/python.exe`、`pythonw.exe`：便携 Python 3.12 命令行/无控制台入口。
- `.runtime/python/python312._pth`：标准库、依赖和项目根目录的搜索路径。
- `.runtime/python/python312.zip`：Python 标准库，属于运行环境而非下载缓存。
- `.runtime/python/*.dll`、`*.pyd`：Python、SSL、压缩、数值及系统接口动态库。
- `.runtime/python/LICENSE.txt`、`python.cat`：许可证及发行完整性信息。
- `.runtime/python/Lib/site-packages/` 内的包源码、动态库和资源：第三方依赖。
- 同目录 `*.dist-info/`：版本、依赖、许可和安装文件记录。
